# v0.18 — Item-тип «Модификатор» + иконки-файлы

## 1. Модификаторы теперь Items, а не хардкод

Раньше список Модификаторов (Вербальность, Ритуал, Скрытые чары, Автономность) жил как
константа в `modifiers.js`, одна на всех персонажей. Теперь это обычные предметы в инвентаре
конкретного актора — тот же единый механизм на флагах, что уже работает для бонусов Путей
(раздел 2.4 дизайн-документа):

- Флаги предмета: `flags.free-magic.isModifier = true`, `flags.free-magic.modifierCost = N`
  (отрицательное — модификатор даёт жетоны в «Токены Маны», положительное — доп. стоимость),
  необязательный `flags.free-magic.modifierIcon`.
- Как и с бонусами Путей — работает для ЛЮБОГО предмета с этими флагами, кем бы он ни был
  создан: кнопкой «+ Модификатор» в панели «Пути Магии» на листе персонажа (новая секция
  «Модификаторы»), вручную выставленными флагами на произвольном Item, или предметом,
  пришедшим от Skill Tree при разблокировке скилла.
- У каждого персонажа теперь свой набор модификаторов — то, что раньше было общим списком
  на весь мир.

Включение/выключение конкретного модификатора **на одну сборку заклинания** осталось прежним
эфемерным состоянием окна Круга (`modsOn`, не персистентно) — просто ключ теперь `item.id`
вместо старой хардкод-строки вроде `"verbal"`.

Окно Круга и окно живого наблюдения ГМа обновляют список модификаторов сами, если во время
открытой сборки модификатор-предмет добавили/удалили/отредактировали (хуки
`createItem`/`updateItem`/`deleteItem`, отфильтрованные по актору).

## 2. Иконки — теперь и файлом из мира, не только классом FontAwesome

Раньше поле "иконка" (у Элементов/Аспектов в Каталоге GM Settings, и теперь у Модификаторов)
принимало только строку класса FontAwesome (`fa-solid fa-fire`). Добавлена возможность
указать вместо этого путь к файлу-изображению, загруженному в мир Foundry — обычный webp/png/
svg/jpg, тем же способом, что уже привычен по полю "Image" на листе актора.

- Новый общий модуль `icon-utils.js`: `renderIconHtml(icon)` сам определяет, что перед ним —
  класс FA (начинается с `fa-`) рисуется как `<i>`, всё остальное — как `<img>`.
  `browseForIconFile()` открывает штатный `FilePicker` Foundry в режиме выбора изображения.
- В Каталоге (вкладка GM Settings → «Каталог») у каждого Элемента и Аспекта рядом с текстовым
  полем иконки появилась кнопка «📁» (обзор файлов) и живое превью.
- В диалоге создания Модификатора — то же самое: поле иконки + кнопка «Обзор...».
- Виджет Ресурса Сцены (v0.16) и все прочие места, где эти иконки показываются, используют
  общий `renderIconHtml` — правка автоматически подхватилась везде без дублирования логики.

## Технически

- Новый файл: `scripts/icon-utils.js`.
- Изменены: `modifiers.js` (Items вместо констант + icon), `circle-app.js`, `gm-viewer-app.js`
  (оба читают модификаторы через `getActorModifiers(actor)`), `sheet-panel.js` (новая секция
  «Модификаторы» + диалог создания с полем иконки), `resource-config-app.js` (обзор файлов +
  превью в Каталоге), `resource-widget.js` (рендер иконок через общий хелпер).
- CSS: добавлены `.fm-icon-img`, `.fm-icon-field-row`, `.fm-icon-browse`, `.fmrc-icon-browse`,
  `.fmrc-icon-preview`, `.fm-mods-hint`, иконки-миниатюры в списках модификаторов.

## Не затронуто в этой версии

- Пути (`PATHS` в `paths.js`) остаются захардкоженными шестью константами с заранее заданными
  иконками — они не проходят через новый файловый механизм (это не пользовательский ввод,
  а фиксированный дизайн шести Путей).
- Освоение/Мастерство модификаторов (условия для применения) — по-прежнему не реализовано,
  как и раньше отмечено в дизайн-документе.
