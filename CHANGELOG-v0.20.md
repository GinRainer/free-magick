# v0.20 — Уровни освоения, Общие модификаторы, перестройка панели листа

Большой архитектурный патч по вашему запросу. Три независимых, но связанных блока.

## 1. Три уровня освоения на каждом модификаторе (звёзды)

Схема данных модификатора (`ModifierDataModel`) расширена: вместо одного набора
Жетоны/Сложность/Эффект теперь **три независимых набора** — `tier1` (Базовое), `tier2`
(Освоение), `tier3` (Мастерство). У предмета есть `currentTier` (1–3) — какой уровень реально
освоен персонажем СЕЙЧАС; именно его цифры используются в расчёте Круга.

- **В листе предмета** — три звезды в шапке, кликабельные: клик по звезде сразу выставляет
  текущий уровень. Ниже — три отдельные секции (по одной на уровень) с собственными полями
  Эффект/Жетоны/Изменение Сложности.
- **Скрытие неоткрытых уровней** — чекбокс «Скрывать неоткрытые уровни от игрока» (виден
  только ГМу). По умолчанию выключен — всё видно всем. Если включить, игрок при открытии
  листа видит вместо текста/чисел уровней выше текущего просто «🔒 Этот уровень ещё не
  открыт» — ГМ по-прежнему видит всё всегда.
- **Заметность в Круге** — у каждой строки модификатора теперь: маленькие звёзды рядом с
  названием, ЦВЕТНАЯ полоса слева (серая = Базовое, фиолетовая = Освоение, золотая =
  Мастерство) — уровень виден с одного взгляда, не читая текст. То же самое в окне живого
  наблюдения ГМа.

## 2. Общие модификаторы (GM Settings → новая вкладка «Модификаторы»)

- Технически — обычные предметы того же типа `free-magic.modifier`, но **мировые** (не
  привязанные ни к какому актору — `Item.createDocuments`, а не
  `actor.createEmbeddedDocuments`). Никакой отдельной схемы данных не потребовалось: тот же
  DataModel, тот же лист предмета — просто без родителя.
- Новая вкладка «Модификаторы» в окне Настройки ГМа: список всех общих модификаторов (иконка,
  звёзды, бейджи стоимости), кнопка «Добавить общий модификатор» (создаёт предмет и сразу
  открывает его лист) и удаление.
- **Автоматически доступны в Круге у каждого персонажа** — `getEffectiveModifiers(actor)`
  подмешивает их к личным.
- **Разделение с личными, как и просили**: если у персонажа есть личный модификатор с ТЕМ ЖЕ
  названием (без учёта регистра/пробелов), общий с этим названием в его Круге не появляется —
  считается, что личная (в т.ч. прокачанная) версия полностью его заменяет. Сравнение идёт
  строго по названию — если хотите другой принцип сопоставления (например, по отдельному
  "ключу шаблона"), дайте знать, это можно будет уточнить отдельно.

## 3. Панель листа персонажа — 2 вкладки

Вкладки «Пути Магии» и «Модификаторы» (кнопки переключения наверху, состояние вкладки
запоминается на клиенте до перезагрузки страницы). Панель расширена с 300px до 420px под
более насыщенный контент.

**Вкладка «Пути Магии»** — сверху новая строка из 4 полей:

| Поле | Источник | Кто редактирует |
|---|---|---|
| Элемент | `scene-resource.js`, назначается в GM Settings → «Игроки» | Никто здесь — только просмотр |
| Круг | новый флаг `magicCircle`, по умолчанию 3 | Только ГМ |
| Тип | новый флаг `magicType`: Одарённый / Маг / Проводник / Нет Типа | Только ГМ |
| Заклинательный Лимит | существующий `spellcast-limit.js` (авто из `@cast`, с переопределением) | Только ГМ (как и раньше в GM Settings, теперь ещё и здесь) |

Игрок все четыре поля видит как обычный текст, без полей ввода — редактирование доступно
только когда лист открывает ГМ (`game.user.isGM`).

Ниже — прежние Токены Путей, без изменений по сути.

**Вкладка «Модификаторы»** — двумя разделами:
- **Личные модификаторы** — карточки (иконка 32×32, название, звёзды, бейджи стоимости
  текущего уровня), клик по карточке открывает лист предмета, крестик удаляет. Кнопка
  «+ Модификатор» вверху создаёт новый и сразу открывает его лист.
- **Общие модификаторы** — те же карточки, но только для чтения (без кнопки удаления, без
  клика на открытие — управляются исключительно из GM Settings), с пометкой «Общий». Уже
  отфильтрованы: те, что заменены личным тёзкой, здесь не показываются (то же правило, что
  и в самом Круге).

## ⚠ Миграция и что проверить

- **Модификаторы, созданные в v0.19** (с одним набором Жетоны/Сложность/Эффект), при загрузке
  этой версии автоматически получат `currentTier = 1` и все данные лягут в `tier1` — но
  Foundry делает это только если поля называются одинаково, а у вас схема поменялась
  структурно (`tokenCost`/`difficultyDelta`/`effect` были на верхнем уровне `system.*`, теперь
  они внутри `system.tier1.*`). **Скорее всего, старые тестовые значения не перенесутся
  автоматически** — проще открыть и перезаполнить тестовые модификаторы заново, раз их пока
  немного.
- Проверьте цепочку целиком: создайте личный модификатор → заполните все 3 уровня разными
  числами → кликните по 2-й звезде (Освоение) → откройте Круг → убедитесь, что используются
  именно цифры 2-го уровня, а не 1-го или 3-го.
- Проверьте общий модификатор: создайте в GM Settings → «Модификаторы» → откройте Круг ЛЮБОГО
  персонажа без личного тёзки → убедитесь, что общий там появился с пометкой «Общий» → дайте
  этому персонажу личный модификатор с ТЕМ ЖЕ названием → общий должен пропасть из его Круга.
- Проверьте права: зайдите не-ГМ пользователем — поля Круг/Тип/Лимит должны быть просто
  текстом, без полей ввода.

Как и с v0.19 — регистрация Item sub-type/листа документа в этой связке Foundry не
протестирована мной вживую, так что при любых визуальных странностях сначала проверяйте
консоль (F12).
